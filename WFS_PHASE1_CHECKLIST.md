> **SUPERSEDED - historical only.** This plans the face in Watch Face Studio, which
> is not how it was built: WFS is a design tool, not the Watch Face Format the face
> actually ships as. Two things below are also wrong as of v1.1.0: the session dials
> are the TOKYO / LONDON / NY **forex** sessions, not XETRA / LSE / NYSE exchanges,
> and their state comes from forex hours, not exchange hours. Session hours are
> defined in exactly one place - `wear-app/.../wear/session/MarketSessionCalculator.kt`.

## STEP 1 — Price split (two text elements)

**1a. Modify val_eurusd (existing layer)**
- Select layer `val_eurusd`
- Change Test Text → `1.185`
- Change Color → `#ffffff` (white)
- Font size: keep current (e.g. 44pt)
- Note the X position of this element

**1b. Add pip digit element**
- Add Component → Text (static)
- Rename layer → `val_eurusd_pip`
- Test Text → `74`
- Color → `#FF7700` (orange placeholder — Phase 2 will switch cyan/orange via condition)
- Font size → **50pt** (slightly larger than val_eurusd to pop)
- Position: same Y as val_eurusd baseline
- Position X: val_eurusd X + ~130px (nudge by eye until flush against "1.185")

## STEP 4 — Battery candlestick (replace Circle Complication)

**4a. Hide old battery Circle Complication**
- Find the battery Circle Complication layer → click eye icon to hide (keep it for reference)

**4b. Import battery_high.png (>50% state)**
- Add Component → More → Preset Image
- Import: `D:\ForexDial\assets\battery_high.png`
- Rename → `battery_high`
- Properties: X=72, Y=200, W=15, H=54
- Add condition: show when BATTERY_PERCENT > 50
  (In WFS conditions panel: add expression using battery system variable)

**4c. Import battery_mid.png (20–50% state)**
- Same steps, file: `D:\ForexDial\assets\battery_mid.png`
- Rename → `battery_mid`
- Same position: X=72, Y=200, W=15, H=54
- Add condition: show when BATTERY_PERCENT >= 20 AND BATTERY_PERCENT <= 50

**4d. Import battery_low.png (<20% state)**
- File: `D:\ForexDial\assets\battery_low.png`
- Rename → `battery_low`
- Same position: X=72, Y=200, W=15, H=54
- Add condition: show when BATTERY_PERCENT < 20
